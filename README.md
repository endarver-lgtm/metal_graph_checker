# NBRB Precious Metals Tracker (Графики драгоценных металлов НБРБ)

Веб-приложение для интерактивного мониторинга, сравнительного анализа и визуализации официальных учетных цен на драгоценные металлы в мерных слитках, устанавливаемых **Национальным банком Республики Беларусь (НБРБ)**.

🌐 **Демо онлайн:** [peaceful-gecko-051b9c.netlify.app](https://peaceful-gecko-051b9c.netlify.app/)

---

## Дизайн-система (Unslop)

Интерфейс переработан по методологии **[unslop](https://github.com/heydamir/unslop)** (Damir Sokolovsky):

* **Direction:**
  * **Product:** Инструмент мониторинга и сравнительного анализа официальных котировок драгметаллов НБРБ.
  * **Character:** Точный, сдержанный, академичный (*calm, exact, technical*).
  * **World:** Финансовые терминалы, банковские хранилища мерных слитков, пробирный надзор.
  * **Moments:** Интерактивный график котировок с чистой сеткой и аналитическим режимом нормализации доходности (Base 100%).
  * **Signature:** Пробирные клейма металлов (`Au 999.9`, `Ag 999.0`, `Pt 999.5`, `Pd 999.8`) и моноширинные числовые котировки в стиле банковского терминала.
* **Сетка и пропорции:** Шаг 4px (Spacing scale: 4, 8, 12, 16, 20, 24, 32).
* **Вложенные скругления (Nested radius math):** Карточки `12px`, контролы `8px`, теги `4px` — отказ от шаблонных круглых pills везде.
* **Типографика:** Системный гротеск для интерфейса + моноширинный стек (`JetBrains Mono / monospace`) с `tabular-nums` для котировок, процентов и дат.
* **Строго без теней и градиентов:** Чистый flat UI, объем задается тонкими разделителями (hairlines) и деликатными перепадами поверхностей.

## Возможности

* **Прямая синхронизация с API НБРБ:** получение актуальных и архивных котировок без сторонних прокси-серверов.
* **Поддерживаемые металлы:**
  * Золото (`Au 999.9`, код `0`)
  * Серебро (`Ag 999.0`, код `1`)
  * Платина (`Pt 999.5`, код `2`)
  * Палладий (`Pd 999.8`, код `3`)
  * Режим **«Все металлы»** — совмещенный график для одновременного сравнения всех 4 активов.
* **Гибкие временные диапазоны:**
  * Быстрые пресеты: `7д`, `1м`, `3м`, `6м`, `1г`, `3г`, `5л`, `Все` (с 2020 г.).
  * Кастомный выбор произвольного диапазона дат через календарь.
* **Обход ограничения API (365 дней):**
  * API НБРБ не отдает более 365 дней за один запрос. В приложении встроен алгоритм прозрачного чанкинга: длительные периоды (3–5 лет) автоматически разбиваются на интервалы по 360 дней и загружаются параллельно.
* **Аналитические метрики периода:**
  * Текущая котировка (BYN за 1 грамм).
  * Динамика за период (абсолютная в BYN и относительная в %).
  * Зафиксированные минимум и максимум с указанием дат.
  * Средняя цена актива.
* **Сравнительный анализ:**
  * Для режима «Все металлы» доступен переключатель: абсолютная цена в BYN либо нормализованная доходность в % (Base 100% на начало периода) для корректного сопоставления динамики золота и серебра на единой шкале.
* **Экспорт:**
  * Выгрузка таблицы котировок в `.csv` (с кодировкой UTF-8 BOM для корректного открытия в Excel).
  * Скачивание графика в формате `.png`.

## Используемые API-методы НБРБ

Документация: [https://www.nbrb.by/apihelp/bankingots](https://www.nbrb.by/apihelp/bankingots)

1. `GET /metals` — список драгоценных металлов и их внутренние коды.
2. `GET /bankingots/prices/[{metal_id}]?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD` — котировки за указанный период (до 365 дней).
3. `GET /v2/bankingots/prices/[{metal_id}]?ondate=YYYY-MM-DD` — официальные цены на конкретную дату.

## Локальный запуск

Приложение полностью статическое и не требует сборки.

### Вариант 1: Прямое открытие
Дважды кликните по файлу `index.html` в проводнике — приложение запустится прямо в браузере.

### Вариант 2: Локальный веб-сервер
```bash
# Через Node.js
npx serve .

# Либо через Python
python -m http.server 8080
```
Затем откройте в браузере `http://localhost:8080`.
